## Sobre o projeto

Este repositório contém a versão publicada do meu portfólio profissional, hospedada gratuitamente com **GitHub Pages**.

A identidade visual combina:

- Estética outonal em tons de laranja, âmbar e carvão;
- Interface responsiva para computador e celular;
- Animações e microinterações em CSS e React;
- Seções de apresentação, projetos, tecnologias, aprendizado e contato;
- Atualização automática da quantidade de projetos públicos considerados no GitHub.

## Estrutura de publicação

- `index.html` — entrada do site;
- `assets/` — JavaScript, CSS e imagem visual do portfólio;
- `.github/workflows/pages.yml` — publicação automática no GitHub Pages;
- `.nojekyll` — evita processamento desnecessário do Jekyll.

Os arquivos dentro de `assets/` são gerados pelo build de produção e são necessários para o site funcionar. Não há senhas, tokens ou chaves privadas neste repositório.
