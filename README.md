## Sobre este projeto

Este repositório publica o portfólio pessoal de **Higor Xavier Galhardo**, estudante do segundo período de Análise e Desenvolvimento de Sistemas.

A proposta é simples: transformar estudos, experimentos e projetos em uma presença profissional na web — com uma identidade visual própria, inspirada em outono, código e evolução contínua.

## O que você encontra no site

- apresentação pessoal e trajetória atual;
- projetos públicos em destaque;
- tecnologias estudadas;
- seção de aprendizado atual;
- links para GitHub e contato;
- layout responsivo para celular e computador.

## Tecnologia do site

`React` · `TypeScript` · `Vite` · `CSS` · `GitHub Pages`

## Publicação

O site é hospedado gratuitamente pelo **GitHub Pages**. A branch `main` contém a versão pronta para publicação; o workflow em `.github/workflows/pages.yml` mantém o deploy automatizado.

Os arquivos dentro de `assets/` são os bundles de produção necessários para o navegador carregar o site. Este repositório não contém banco de dados, login, senhas ou chaves privadas.
